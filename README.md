## ✨ Возможности

- 💰 **Окно 1** — сколько потратили
- 🏷️ **Окно 2** — за сколько выставили
- 📦 **Окно 3** — итог после вычета комиссии
- 💎 **Заработок** — чистая прибыль
- 🎯 **Кнопка «Окуп»** — введи любую желаемую прибыль (50, 100, 200, 500 или свою), и калькулятор сам подберёт цену продажи
- ⚡ **Быстрые кнопки** — +50, +100, +200, +500
- 🌍 **Валюты** — RUB, USD, EUR, KZT, UAH, CNY
- 🌙 **Тёмная тема** — кнопка в правом верхнем углу

## 🎯 Как пользоваться кнопкой «Окуп»

1. Введите в **Окно 1** сумму, которую потратили
2. В поле **«Окуп на»** введите желаемую прибыль (например, 150)
3. Нажмите **«Рассчитать цену»**
4. Цена в **Окне 2** изменится автоматически
5. Внизу увидите: **«ЗАРАБОТАЛ: 150 ₽»**

Или нажмите одну из быстрых кнопок: +50, +100, +200, +500
