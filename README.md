## ✨ Возможности

- 💰 **Окно 1** — сколько потратили
- 🏷️ **Окно 2** — за сколько выставили
- 📦 **Окно 3** — итог после вычета
- 💎 **Заработок** — чистая прибыль
- 🎯 **Кнопка «Окуп»** — введи любую прибыль (50, 100, 200, 500 или свою), калькулятор сам подберёт цену
- ⚡ **Быстрые кнопки** — +50, +100, +200, +500
- 🌍 **Валюты** — RUB, USD, EUR, KZT, UAH, CNY
- 🌙 **Тёмная тема** — кнопка в правом верхнем углу
