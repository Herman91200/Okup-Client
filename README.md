## ✨ Возможности

- 💰 **Окно 1** — сколько потратили
- 🏷️ **Окно 2** — за сколько выставили
- 📦 **Окно 3** — итог после вычета
- 💎 **Заработок** — чистая прибыль
- 🎯 **Кнопка «Окуп»** — введи любую прибыль (50, 100, 200, 500 или свою), калькулятор сам подберёт цену
- ⚡ **Быстрые кнопки** — +50, +100, +200, +500
- 🌍 **Валюты** — RUB, USD, EUR, KZT, UAH, CNY
- 🌙 **Тёмная тема** — кнопка в правом верхнем углу

---

## 🎯 Как пользоваться кнопкой «Окуп на»

1. Введите в **Окно 1** сумму, которую вы потратили (например, `10000`).
2. В поле **«Окуп на»** укажите желаемую чистую прибыль (например, `150`).
3. Нажмите зелёную кнопку **«Рассчитать цену»**.
4. Калькулятор автоматически подставит нужную цену в **Окно 2**.
5. В блоке **«ЗАРАБОТАЛ»** отобразится ваша прибыль (в примере — `150 ₽`).

> 📌 **Быстрые кнопки** (`+50`, `+100`, `+200`, `+500`) позволяют одним кликом задать желаемую прибыль и сразу пересчитать цену.
