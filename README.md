# 🌱 Калькулятор «Окуп» — для Playerok и StarPets

**Мгновенный расчёт цены перепродажи с учётом комиссий**

👉 **[ОТКРЫТЬ КАЛЬКУЛЯТОР](https://herman91200.github.io/Okup-Client/)** 👈

---

## ✨ Возможности

- 💰 **Окно 1** — сколько потратили на товар
- 🏷️ **Окно 2** — за сколько выставили на продажу
- 📦 **Окно 3** — итог после вычета комиссии
- 💎 **Заработок** — ваша чистая прибыль
- 🌱 **Зелёная кнопка «Окуп»** — одним нажатием устанавливает цену для получения **ровно 100₽ прибыли**

---

## 🎯 Как пользоваться кнопкой «Окуп»

1. Введите в **Окно 1** сумму, которую вы потратили (например, `10000`).
2. Нажмите на **зелёную кнопку «Окуп»**.
3. Калькулятор сам подставит нужную цену в **Окно 2**.
4. В блоке **«ЗАРАБОТАЛ»** отобразится ровно `100 ₽`.
